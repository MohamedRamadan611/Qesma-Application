Implement: Firebase initialisation, permission flow and settings entry (the notification settings screen from FL15 gains a "push enabled" status row), token registration service, message handlers, tap routing, ARB strings, scope-guard allow-list for `push`, docs update (`docs/mobile-release.md`: Firebase setup, signing, what to verify on a device).
Tests: token registration/unregistration order on sign-in/out (fake API), permission states, tap routing for each type from foreground/background/terminated using fake message events, signed-out routing, dedupe, payload parsing never throws on unknown types, release-artifact check still passes, log-capture (tokens never logged); a device checklist added to `docs/gates/mobile-device-checklist.md` (real push on a real device, denied permission, airplane mode).
Constraints: optional prompt: the app builds and runs without Firebase files when push is disabled by config; no secrets in git; Android first. Done when analyze and tests pass and the release build check passes. Then Stop protocol; do NOT start FL18.
