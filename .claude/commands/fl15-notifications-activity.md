Implement:
1. **Notification center**: list grouped by day, unread dot + semantics ("غير مقروء"), tap to open and mark read, "تعليم الكل كمقروء", empty state, badge in the entry point, refetch on resume.
2. **Group activity feed** (P14-02): vertical timeline with initials avatars (no photos), the Arabic sentence, relative time, tap-through; keyset paging.

4. ARB strings (all event templates, ar primary, en secondary, plural rules for counts); scope-guard allow-list for `notification*`.

Tests: one rendering test per event type (sentence, actor, amount via formatter, ar/en); unknown type fallback; day grouping across midnight/timezone fixtures; keyset pagination and no duplicates on refresh; mark-read optimistic path and rollback; unread badge updates; tap-through route per type incl. deleted expense; settings toggles and rollback on error; widget tests ar/en/2.0; goldens for the center, the feed, the settings; a11y semantics (unread state announced); guard: no money arithmetic, no names stored client-side beyond memory.
Constraints: SCREEN_MAP rules; no push here (FL17); no real-time sockets or polling timers; do not persist notification content on disk. Done when analyze and tests pass. Then Stop protocol; do NOT start FL16.
